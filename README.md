# ScrollPilot

ScrollPilot is a small macOS app that lets you quickly toggle natural scrolling from the menu bar.

It adds a lightweight status item to the top-right of the screen, so you can switch between natural and non-natural scrolling in one click without opening System Settings.

Initial goal for this project was to automatically switch to natural scrolling for trackpads and disable it for mice (especially Magic Mouse). I didn't get this to work under macOS 27, so I ended up just to create a toggle for manual switching.
Maybe I somehow can realize the automatic switching later.
